# API REST de Usuarios - ASP.NET Core

## Descripción

API REST desarrollada con ASP.NET Core y Entity Framework Core utilizando el enfoque Code First.

La API permite:

* Crear usuarios
* Validar correos electrónicos duplicados
* Crear categorías
* Crear proveedores
* Crear productos
* Consultar usuarios
* Consultar categorías
* Consultar proveedores
* Consultar productos
* Actualizar usuarios
* Actualizar proveedores
* Actualizar categorías
* Actualizar productos
* Eliminar usuarios
* Eliminar proveedores
* Eliminar categorías
* Eliminar productos

---

# Tecnologías utilizadas

* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger
