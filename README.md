# API REST de Usuarios - ASP.NET Core

## Descripción

API REST desarrollada con ASP.NET Core y Entity Framework Core utilizando el enfoque Code First.

La API permite:

* Crear usuarios
* Consultar usuarios
* Actualizar usuarios
* Eliminar usuarios
* Validar correos electrónicos duplicados

---

# Tecnologías utilizadas

* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger
